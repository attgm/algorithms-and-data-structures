# Pythonによるアルゴリズムとデータ構造

Pythonで「アルゴリズムとデータ構造」を教えることを想定して作成した講義スライドです。
基本的なアルゴリズムとデータ構造を、図とPythonの実装例を通して説明します。型ヒントや dataclass を使い、データの型や構造も示しています。

授業や自習での利用、授業内容に合わせた編集がしやすいよう、Marp形式のソースと図・サンプルコードを公開しています。
出力されたスライドは[Speaker Deck](https://speakerdeck.com/attgm/algorithms-and-data-structures)で公開しています。



## スライド内容

以下の内容を含みます

- ソート
  - バブルソート
  - 挿入ソート
  - クイックソート
  - マージソート
- 探索
  - 線形探索
  - 二分探索
  - ハッシュ探索
- データ構造
  - スタック
  - キュー
  - リングバッファ
  - 連結リスト
  - 二分探索木

## 想定読者と学習方針

Pythonの変数・条件分岐・繰り返し・関数の基礎を学んだ方を対象としています。
オブジェクト指向の事前知識を前提とせず、アルゴリズムとデータ構造の基本を学ぶことを目指します。
型ヒントや `dataclass` など、実装例を読むために必要な機能は資料内で説明します。

## 対象とするPythonのバージョン

Python 3.10以上を想定しています。
